# 《灵枢战纪》十一色构筑评测 · kimi28preview

> 信息源仅限 `agents/brief/01_基本规则.md` 与 `agents/brief/02_卡表.md`。
> 评测视角：1v1、30 张、20 血（=生命卡组张数）、疲劳与 21 轮灼烧兜底。
> 共识前提：20 血 + 每回合稳定 1~2 张卡的资源下，**能在 5~8 回合持续施压**的颜色天然占优；门槛制（红/蓝/银/粉）空转风险低但吃每回合打出上限；消耗制（白/黑/绿/紫/橙/青/金）看引擎自洽度；金最特殊，是「行动值链」套牌。

---

## 一、白（AP 制 · 守护军团 / 信仰升华 / 谐律指挥官）

1. **资源机制**：AP 每回合 3 点，T5 起 4、T9 起 5；消耗制，没存留。开局 3 张、回合开始抽 1——是全游戏最慢的过牌之一。还有 AP 卡（横置 +1 AP）可放 3 张，等于把「回合上限」挪了一点到节奏里。打法天然是「一回合拍 1~2 个 2~3 费单位」的节奏中速。
2. **胜利方式与节奏**：T2~T3 开始铺 2/1/2、2/1/2 圣盾，T4~T5 靠团结轻骑/军团中坚膨胀站场，T6 以后用圣光震荡/肃正之槌保场、骑士长·加百列（谐律 SR3）补一波 4/3/5 压死。没有直伤，胜利画面是「场面 +1、对手解不动」。
3. **关键卡**：
   - LQ01-002 团结轻骑：前期 ATK 发动机，2 费最值钱的一格；
   - LQ01-010 募兵号令：2 费铺 2 个守护1 士兵，一卡成场面；
   - LQ01-008 军团中坚：团结+守护1 的定场单位；
   - LQ01-004 救赎圣辉 / LQ01-013 升天圣契：续航与「永久移除对手伤害」的升天轴（只对白内收益高）；
   - LQ01-260 白银骑士长·加百列：唯一的降维压制点。
4. **结构性弱点**：抽牌太慢，断抽即断节奏；全家没有穿防手段，被一堵带守卫的大墙（绿泰坦、重装要塞）单卡停住；面对橙的千叠锻浪/银的终章齐鸣这类循环清场，铺两次就没了；对阵红，3 血前的场面经常来不及展开。
5. **30 张构筑**：奥蕾莉亚（1AP 生士兵，被动守护1，铺场引擎）。曲线 1~2 费 12、3~4 费 15、5 费+ 3。名目（10×3）：圣光新兵 / 团结轻骑 / 圣盾亲卫 / 募兵号令 / 守护阵列 / 军团中坚 / 圣光震荡 / 救赎圣辉 / 肃正之槌 / 见习调律师（服务加百列的调律师素材）。必带：募兵号令、团结轻骑、圣光震荡。

## 二、黑（牺牲值 · 磨牌循环 / 魂铸 T8）

1. **资源机制**：牺牲值每回合 `2+⌊回合/2⌋`，T10 起 12/回合，是后期产出最高的消耗制；靠 019/027/034/026/灵体磨损把「受伤/牺牲」转成牺牲值。特殊福利：生命 ≥12 时可付 2 生命抽 1（每回合至多 2 次）——黑是唯一能把生命当牌用的颜色，但和自己的斩杀线共享资源。
2. **胜利方式与节奏**：前期用墓道行尸/工蚁占场，牺牲值花在骨窖绞杀/亡绝祷歌上解场兼磨牌；中期拾烬者+永夜墓碑构成「复活循环」滚雪球；T8 以后魂铸外枢（万骨王座/百刑巨人，素材 SR 合计 ≥6）作为终结。节奏偏中速控制，取胜画面是解光对面 + 巨人压场。
3. **关键卡**：
   - LQ01-027 自笞者 / LQ01-034 石心祭品：牺牲值发动机；
   - LQ01-029 拾烬者：复活引擎核心，跨卡合并的每回合上限意味着它和泽拉斯/墓碑是同一本账；
   - LQ01-032 永夜墓碑：复活轴的抽牌与 +1/+1；
   - LQ01-023 聚骸之地：磨牌地标，重构减费；
   - LQ01-263 万骨王座 / LQ01-264 百刑巨人：魂铸终结。
4. **结构性弱点**：引擎要两张卡（拾烬者+墓碑）+ 两三回合才转起来，且两者身材平庸；魂铸素材 SR 偏高（合计 ≥6），卡组里 SR3~4 单位浓度不够时外枢迟迟召不出；抽牌靠卖血，碰到红的直伤（焚天血咒、殉道血誓）等于替对手开火力；对粉的「挡不住的骑升灵体」几乎没有答案。收官手段只有大单位，怕冻结怕清场（亡绝祷歌对方也会算）。
5. **30 张构筑**：泽拉斯（弃牌区费用 −1 + 每回合复活 1，和 029/032 天然耦合；若想打自残巨人再换莫德里斯）。曲线 1~2 费 15、3~4 费 12、5 费+ 3。名目（10×3）：石心祭品 / 自笞者 / 墓道行尸 / 墓穴挖掘工 / 骨窖绞杀 / 聚骸之地 / 拾烬者 / 永夜墓碑 / 亡绝祷歌 / 融魂工匠。必带：石心、拾烬者、墓碑、亡绝。

## 三、红（激情门槛 · 无升灵 · 纯快攻）

1. **资源机制**：激情 = `min(2×回合, 10)`，**门槛不消耗**——满激情（T5 起恒定 10）等于「全手牌免费打」。补偿机制：回合开始不抽，回合末弃光补至 `(10−激情)÷2`；用掉激情反而降低补牌量，所以红的正确姿势是「低费全出 + 把 5 费以上的卡（战意永燃/血红爆发）留到激情溢出回合」。
2. **胜利方式与节奏**：T1 赤刃幼虎、T2 熔岩裂爪/掷火散兵，3~4 回合内场攻即可到 6+；中期靠烽燧传令官免费拉一个 ≤2 激情的单位打爆发，T6~T7 用血红爆发+冲锋群收尾（配合灵体拉格纳被动全冲锋、启动过载+1 IMP，理论斩杀在 8~10 点/回合）。是全环境最快的时钟，5~7 回合内结束战斗是常态。
3. **关键卡**：
   - LQ01-037 赤刃幼虎 / LQ01-038 怒火新兵：1 费冲锋，快攻地基；
   - LQ01-041 烈阳断刃：瞬间 3 点，能反制窗口用，攻防一体；
   - LQ01-053 烽燧传令官：节奏爆点，白送一个单位；
   - LQ01-046 血红爆发：专用终结，按本回合攻击次数追伤；
   - LQ01-045 战意永燃：全体冲锋的中期过载件。
4. **结构性弱点**：后期弹药最薄——回合末补牌看 `(10−激情)÷2`，满激情只补 0 张，一回合没打死就进入「每回合摸啥打啥」；没有任何硬解（只有烈阳断刃 3 点），面对第一堵高耐久守卫墙必须送怪换；怕蓝的冻结、白的守护阵列、青的潮汐帷幕这类「攻击税」；第 21 轮灼烧到来前打不死长盘控制就自动输。
5. **30 张构筑**：拉格纳（被动全冲锋——这是红灵体里唯一改变游戏规则的）。曲线压到极限：1 费 9、2 费 12、3 费 6、4~6 费 3。名目（10×3）：赤刃幼虎 / 怒火新兵 / 熔岩裂爪 / 掷火散兵 / 烈阳断刃 / 血斧掷颅手 / 烬原猛虎 / 暴走狂犬 / 焚天血咒 / 血红爆发。必带：四张 1~2 费冲锋、烽燧传令官→考虑踢掉一张 4 费（如暴走狂犬）换满编 053。

## 四、绿（法力+地标 · 加速/巨兽/升灵 三流派）

1. **资源机制**：法力每回合 `2+地标数`，消耗制；地标同时是法力引擎和「地标计数」资源。地标越多，法力越高、过牌越多（回合末补至地标数+1），自我滚雪球。青/绿共用「法力」一词但绿靠地标堆量、青靠回合自然成长（上限 6）。
2. **胜利方式与节奏**：T1 地标、T2 地标+藤根、T3 林冠漫步者（地标 ×3 时已是 5/5/3），T4~T5 践踏巨兽（荒原猛犸/裂地巨犀）+ 巨兽冲锋贴践踏；T7~T8 泰坦或兽王之魂（魂铸 SR5 用两个 SR2+一个 SR1 即可）终结。是节奏最标准的「加速中速」。
3. **关键卡**：
   - LQ01-061 母神共鸣地 / LQ01-062 涌泉林地 / LQ01-064 大地脉动：地标浓度件；
   - LQ01-063 林冠漫步者：地标计数的人形膨胀器；
   - LQ01-065 荒原猛犸 / LQ01-066 裂地巨犀：践踏中坚；
   - LQ01-067 林冠泰坦：6 费 6/5/6 践踏再生，逼近费用极限身材的收官；
   - LQ01-268 兽王之魂：全绿最容易凑的魂铸外枢（SR5），降临全体践踏。
4. **结构性弱点**：极怕地标被拆（灰 011 拆解/016 驱逐都能单点地标体系外的单位，但地标本身怕针对节奏断档）；「地标+生物」两手都要抓，起手缺一即慢半拍；践踏怕高密度小墙（衍生物铺场：银/白），溢出伤害打不出来；面对红的 5 回合时钟，绿的神仙身材经常只攻击一次就到斩杀线了。
5. **30 张构筑**：森林先知·盖亚（地标放置 1.5 张/回合 + 免费铺地标，引擎顶点）。曲线：1 费 6、2 费 9、3 费 9、4~5 费 6（泰坦看对局浓度，可 2~3）。名目：盖亚幼株 / 幼叶之池 / 母神共鸣地 / 涌泉林地 / 大地脉动 / 摇篮藤根 / 林冠漫步者 / 猎杀弱肉 / 荆棘绞杀 / 落叶风暴（3 张）＋荒原猛犸×3 / 裂地巨犀×3 / 巨兽冲锋×3（即 12 名目 30 张，巨兽浓度必须拉满）。外枢：兽王之魂+巨木之心。必带：三套地标件、漫步者、猛犸、冲锋。

## 五、蓝（手牌门槛 · 纯控制）

1. **资源机制**：资源=手牌张数（每回合抽 2，蓝手牌无上限不参与弃牌），**门槛不消耗**但每回合限打 2 张。越抽越能打、越打越抽：084 演算矩阵（首次抽牌+1）+ 088 预示之镜 + 085 无穷级数 构成单回合过 5~6 张的引擎。阿基米德灵体在手牌 >7 时给法术 −1 费（虽是门槛制也有实际减免）。
2. **胜利方式与节奏**：前 4 回合几乎没有施压能力（手牌 3~4，出的全是 1/1/1 和 2/2/2）；节奏点全在防守——冻结（076/080/082）、反击（077）、永冻领域、时间尽头（手牌 6 重置全场）；取胜靠「耗干对手 → 大墙踢死」，或靠蓝色生命卡的抽牌差把疲劳战打成必赢。终局终端是 LQ01-082 灭界巨构（战吼冻全场）+ 永冻领域锁攻击，实际斩杀偏慢。
3. **关键卡**：
   - LQ01-084 演算矩阵：引擎之心；
   - LQ01-077 抑能重击 / LQ01-296（灰逆流）：反击墙，蓝的合法性来源；
   - LQ01-078 时间尽头：唯一真正的清场（回手而非消灭，吃衍生物/token 泛滥对局）；
   - LQ01-085 无穷级数：滤牌核心；
   - LQ01-082 灭界巨构·冰狱枢机：最大最强的一个「生物答案」。
4. **结构性弱点**：没有硬解只有冻结（冻结不解场，对面攒着解冻照样踢）；攻击维度贫瘠，遇到「不解也能赢」的对局（如金的经济流、黑的磨牌流）无所适从；手牌门槛意味着被断抽（断粮、抑能反击）后连防守都打不出；对红这种不给你时间的颜色胜率最差，且红的瞬间直伤不吃反击。
5. **30 张构筑**：阿基米德（手牌 >7 法术 −1；梅林池外）。曲线：1~2 费 9、3~4 费 15、5 费+ 6。名目：筹算学徒 / 先觉之镜 / 预示之镜 / 演算矩阵 / 无穷级数 / 抑能重击 / 霜结咒阵 / 静默哨兵 / 永冻领域 / 时间尽头（3×10），外挂 082 巨构×2~3。必带：矩阵、无穷级数、抑能重击、永冻领域、时间尽头。

## 六、紫（骰池 · 混沌惩罚 · 高方差）

1. **资源机制**：每回合铸 1~3 枚 D6 进池（上限 5+灵体加成，卡奥斯 +2），回合开始投全部求和为灵脉，消耗制。D6 期望 3.5，混沌每点 −3 惩罚极痛；D10/D12 各限 1 枚是后期爆点。灵脉在回合开始结算、当回合用完——没有跨回合存留。
2. **胜利方式与节奏**：理想曲线是 T1~T2 铸 D6、T3 凯（D10+清混沌）、T5~T6 上 D12，T6~T7 一发「虚空奇点」（灵脉÷2 伤害，期望值 6~9 点）或万物归虚（全单位 −4 耐久）收头。但只有卡奥斯灵体能同时多铸、扩容、重投，把方差压下来。
3. **关键卡**：
   - LQ01-098 钟摆占卜师·凯：混沌清零器，骰池体系保险丝；
   - LQ01-106 万面天使·喀戎：唯一铸 D12，后期灵脉上限来源；
   - LQ01-102 虚空奇点：按产出比例点杀/打脸的高上限终结；
   - LQ01-104 终焉禁咒·万物归虚：6 费全屏 −4 耐久，自带「不触发受伤时」的清场；
   - LQ01-092 虚空侍僧·格罗 / LQ01-101 虚空掠夺者：虚空献祭轴，手牌转灵脉。
4. **结构性弱点**：全游戏方差最大的颜色——掷不出大数时 6 费终焉清不掉 4 耐久墙、虚空奇点打 4；混沌 +1 惩罚 −3 灵脉，没有凯时连续大失败直接空过；手牌补给最差（无常规抽牌，≤2 才补 1）；没有生物质量，骰子小就是一堆 1/1/1、2/1/2 白送；T1~T4 对场面零贡献，怕一切快攻。
5. **30 张构筑**：卡奥斯（铸造 −1、池容量 +2、每回合 2 铸、重投——四重保险，必带）。曲线：1~2 费 15、3~4 费 12、5~6 费 3。名目：掷骰学徒 / 虚空侍僧 / 虚空奔涌 / 窥虚之瞳 / 命运重掷 / 混沌骰虫 / 钟摆占卜师 / 骰池扩容·法阵 / 湮灭之指 / 虚空掠夺者（3×10），外挂 106 喀戎×2~3 / 102 奇点×2~3 / 104 终焉×1~2。外枢：万象编织兽/原初混沌。必带：凯、D12、扩容法阵、湮灭之指。

## 七、橙（锻造 · 装备/淬炼 · 锻铸联结）

1. **资源机制**：锻造值每回合 `3+锻造区装备产出`（上限 10），消耗制；装备既能挂单位也能横置进锻造区产锻造值（区上限 6 件）——装备是「双重资源」。回合开始抽 2、区里有装备再 +1，润滑全色前列。引擎思路：装备铺进锻造区 → 锻造值 6~9/回合 → 既可拍大单位也可烧淬炼连锁。
2. **胜利方式与节奏**：T1~T2 铺 1~2 费装备+单位、T3 铁壁队长/重盾站场、T4~T5 用千叠锻浪（每个淬炼指示物对全体敌 1 点）或钢铁联盟·全线开工产 6 金式爆发过渡，T6~T7 联结外枢（行星级锻炉 8/5/8 或欧米伽 6/5/7）终结；也可以走快攻向：速淬短刃+冲锋单位 T3 开始踢。
3. **关键卡**：
   - LQ01-116 淬核巨锤：装备区里「既产 2 又挂 +2/+1」的质量件；
   - LQ01-117 淬火号令 / LQ01-118 淬河·千叠锻浪：淬炼连锁的放置与引爆，AOE 核心；
   - LQ01-122 批量锻造 / LQ01-123 布线学徒：装备调度，引擎稳定器；
   - LQ01-126 中枢调度：每次联结后抽 1+锻造 +2 的滚雪球结界；
   - LQ01-272 巨构·行星级锻炉 / LQ01-273 中枢禁卫·欧米伽：锻铸联结终结。
4. **结构性弱点**：装备怕拆（灰 011 拆解一卡换一卡+节奏断）；淬炼链要「先叠 3 层再引爆」，被快攻 T4 抢死时连锁来不及转；区里装备越多手牌越少（装备卡本身占抽牌位）；对粉的骑升灵体，装备墙拦得住普通单位拦不住「不可被战斗破坏的灵体」；灵体弗吉奥是唯一减淬炼需求的，但和布鲁诺（−1）不叠加同侧。
5. **30 张构筑**：弗吉奥（淬炼需求 −1，使 117 两发就满）。曲线：1 费 9、2 费 12、3 费 6、4~5 费 3。名目（10×3）：军械新兵 / 淬火学徒 / 速淬短刃 / 制式军刀 / 双股锻钳 / 冷却守卫 / 淬层监工 / 淬火号令 / 批量锻造 / 甲卫重盾（3×10），外挂 116 巨锤×2~3 / 118 锻浪×2~3 / 126 调度×2。外枢：锻炉+欧米伽。必带：装备三件套、号令、锻浪、调度。

## 八、青（法力上限 6 · 潮汐/流转 · 连击引擎）

1. **资源机制**：法力每回合 `min(回合+1, 6)`（消耗制），天然 6 费封顶；补牌强——回合开始抽 2，回合末按本回合打出数每 2 张抽 1（流转）。潮汐是全局相位（涨/退潮），由卡面切换；青的单位与解牌大多吃相位。最大特色：**回响+连击+涡流**让单回合能结算多次法术（风暴脉冲结算两次、幻象连击复制法术、涡流长老按出牌数涨 ATK）。
2. **胜利方式与节奏**：T2 潮汐号令切潮+抽 1、T3 深海重压/风暴脉冲解场、T4 涡流长老（本回合每用一张 +1 ATK，理想 6/2/4）压场、T6 月潮终曲·海灵圣母（5/4/7 战吼全体 +1/+1）收官；外枢潮汐共鸣锚的「每次切潮对对手 1 点」是慢性直伤。取胜靠场面质量+补牌续航，直伤为零。
3. **关键卡**：
   - LQ01-129 潮汐号令 / LQ01-130 潮位罗盘：潮汐切换与切换抽牌，节奏心脏；
   - LQ01-131 深海重压 / LQ01-132 风暴脉冲：相位+回响的双倍解；
   - LQ01-140 涡流长老：连击流的唯一大生物；
   - LQ01-136 月潮终曲·海灵圣母：唯一一张「大」牌；
   - LQ01-275 潮汐共鸣锚：切潮烧血，最接近直伤的东西。
4. **结构性弱点**：**没有终结手段**——最好的大生物是 5/4/7，最好的直伤是每切潮 1 点，打控制卡组打到疲劳都赢不了；引擎件彼此依赖（连击要第二张牌、回响要复制目标），单张上手经常空转；潮汐是双方共享的相位，对手也能利用（深海重压退潮 4 点的收益可能送给对面）；6 费法力上限锁死了后期爆发。
5. **30 张构筑**：温蒂妮（横置 1AP 切潮 + 退潮抽 2，池外泽菲不可选）。曲线：1~2 费 15、3~4 费 12、5~6 费 3。名目（10×3）：潮汐幼灵 / 溅跃小妖 / 潮汐号令 / 潮位罗盘 / 深海重压 / 风暴脉冲 / 涨潮反击 / 连击共鸣 / 涡流长老 / 调律学徒，外挂 136 圣母×2~3 / 135 潮汐帷幕×2~3。外枢：共鸣锚+深渊潮主。必带：号令、罗盘、重压、脉冲、涡流长老。

## 九、银（共鸣门槛 · 门槛配方 8/11/8/2/1）

1. **资源机制**：共鸣 = `max(1, 场上卡牌数+地标数)`（回合开始快照），**门槛不消耗**——意味着只要场面不被清，所有银卡当回合免费出；代价是每回合限打 3 张+回合末只补至 `min(max(共鸣,3),5)`。下限 1 修正保证首回合能出牌。本质是「铺场即法力」。
2. **胜利方式与节奏**：T1 银翼列兵/方阵学徒、T2 战马+衍生物、T3 方阵壁垒+征募长号爆发铺 3~4 个单位、T4~T5 终章齐鸣（共鸣÷2 向上取整的全屏 AOE）或方阵巨像（5/4/6）；共鸣破坏机制（己方卡被破坏累积、resonanceDmg 消费）让「送衍生物」也能变成直伤。取胜画面是场面铺满 + 齐鸣清场后衍生物继续踢。
3. **关键卡**：
   - LQ01-145 银翼列兵 / LQ01-151 银翼战马 / LQ01-148 列阵：铺场三件套；
   - LQ01-150 征募长号：共鸣 2 从牌库顶再铺 2 个银翼，浓度引擎；
   - LQ01-149 方阵壁垒：+0/+1 群体+抽 1，攻防一体；
   - LQ01-158 终章齐鸣：全屏 AOE 收头/清场；
   - LQ01-278 谐律魔导堡垒 / LQ01-279 终焉巨械：低成本外枢（阶级 2/4，衍生物即可作素材）。
4. **结构性弱点**：单卡质量平庸（最好身材 5/4/6），全部依赖场面数量——被 AOE 清空后共鸣阈值跳水，3 回合才能重建；共振等级÷2 的 AOE 打 20 血太慢，真正的斩杀手只有终焉巨械的「去除素材：对对手 3 点」；方阵阵型怕践踏（高密度小墙被溢出伤害穿死）；回合末补牌上限 5，续航封顶。
5. **30 张构筑**：艾莉丝（银翼集群 +1、征募 4——铺场浓度再翻倍）。按门槛配方思路低门槛拉满：共鸣1 段 12 张（列兵/长枪兵/枪骑兵/列阵 各×3），共鸣 2~3 段 12 张（战马/方阵壁垒/征募长号/方阵整列 各×3），共鸣 4~5 段 6 张（重装要塞×2 / 终章齐鸣×2 / 方阵巨像×1 / 升格逆鳞×1）。外枢：魔导堡垒+终焉巨械。必带：征募长号、方阵壁垒、终章齐鸣、战马。

## 十、粉（灵压门槛 · 骑升/魂装 · 每回合限打 2）

1. **资源机制**：灵压是等级 `[0,2,4,6,8]`，下限 1，**门槛不消耗**、每回合限打 2 张。真正的资源是骑升阶梯：T2 起每回合 1 次 ride，成功率 0.5，成功后灵压跳档、AP 上限 +1（→4），原灵体变魂装源；AP 每回合重置为 `2+骑升成功次数`。Lv4 期望在 T8~T10 到达——粉是全游戏唯一「等级=时间」的颜色。
2. **胜利方式与节奏**：前 3 回合几乎只在做两件事：ride 失败时用束装侍从/迅影狐占场、用献装/双轨心音把单位叠进灵体下方攒魂装源；T5~T6 灵体亲自作战（Lv2 蕾 3/2 每回合 1 次、耗 1AP），魂装源每 2 个 +1 ATK/IMP，疾风翼叠上后每拳追加 1 冲击；T8 以后 Lv4 蕾（6/4，每回合 2 次攻击、疾风结算两次）单回合 4 拳 16+ 直伤。胜利画面是「一个打不死的灵体用拳头数数」。
3. **关键卡**：
   - LQ01-170 解放引导：本回合 ride 不耗 AP+抽 1，骑升成功率是固定 0.5，解放引导管的是「AP 够不够连续骑」；
   - LQ01-165 献装 / LQ01-168 双轨心音：魂装源的批量生产与过牌；
   - LQ01-171 魂装·疾风翼：灵体疾风化，直伤放大器；
   - LQ01-175 深红摇篮 / LQ01-255（莉莉丝 Lv4）：粉的「伪生命回复」，与 20 血机制深度咬合；

4. **结构性弱点**：ride 0.5 是纯随机——连续失败两次就白让两回合灵压，节奏直接崩；每回合限打 2 张是硬顶，中盘爆发力全色最低；灵体伤害不吃场面阻挡但也穿不了「灵体减伤」（白守护阵列/永冻领域/青潮汐帷幕都是对灵体的税）；魂装轴被拆结界（双轨心音中断）或被快攻抢死（T5 前 20 血只剩 10）都无力回天。

## 十一、金（金币 · 市场 · 行动值链 · 10 固定+市场牌库）

1. **资源机制**：金币每回合 `5+金币卡产出`，回合末清零（除非 207 囤积居奇保留 3）；真正的瓶颈是**行动值链**：av 每回合重置为 1，每出 1 张 −1，「行动+X」卡补回。固定牌库里 181 铜币×4（行动+1）、182 银币×2（行动+1）、185 灵活位（行动+1）+ 市场 8 张「行动+」引擎（186/187/188/189/190/191/192/193），金的每一回合都是在「打一张→补 1 行动→再打一张」的链式调度里渡过的。回合末弃光重抽 5，牌序即战术。
2. **胜利方式与节奏**：T1~T2 用铜币+雇员铺经济、T3 买分拣线/当铺学徒转起来、T4~T5 市场操纵+竞价员减费后买托拉斯（5/3/5，垄断 +1/+1）或股票砸盘（全屏 2）；胜负手在于「当回合产出全换成购买力」的节奏——保险库（每回合 2 金）+ 囤积居奇（保留 3）建立滚雪球，白手套（4/4/4 免费买 1 次）是爆发回合的顶点。20 血环境下，金是「中速节奏+经济压制」，斩杀靠高质量单位而非直伤（212 砸盘是唯一 AOE）。
3. **关键卡**：
   - LQ01-188 分拣线（行动+1、购买 −1）/ LQ01-206 保险库（每回合 2 金）：经济双引擎；
   - LQ01-193 远洋公司·控股股东（市场操纵换牌）：解决「市场没货」的随机性；

4. **结构性弱点**：行动链一断（没摸到行动+卡、或 209 贴现票据/189 当铺学徒被迫先手交掉）整回合只能打 1 张，经济直接雪崩；市场购买后牌进弃牌区再抽回，节奏比想象慢半拍；没有继承点特殊胜利（245 摩根不在池），20 血只能靠单位磨；怕橙的千叠锻浪/银的齐鸣这类「不管你经济先清你场」的 AOE。

## 十二、我的排序（构筑潜力 · 高→低）

**红 ＞ 橙 ＞ 银 ＞ 绿 ＞ 粉 ＞ 金 ＞ 黑 ＞ 白 ＞ 蓝 ＞ 紫 ＞ 青**

### 前三

1. **红**：20 血 + 冲锋池密度最高的环境下，红是唯一「按回合收钱」的颜色。T1 出怪、T5 恒定 10 激情全免费、血红爆发按攻击次数追伤、灵体全冲锋——曲线、引擎、终结三位一体，且对局越短红的方差越被压缩。缺点是被一堵墙单卡停，但「一堵墙」也要对面先活到出墙。
2. **橙**：资源与过牌双优（锻造 3+装备、回合开始抽 2+1），装备既能变现成身材也能变现成 AOE（淬炼链），两套终结（锻炉/欧米伽）素材都是自产装备、契合度极高。快慢两吃：速攻向 T3 贴刀冲锋、控制向 T6 千叠锻浪清场。上限比红低、下限比红高，综合第二。
3. **银**：门槛制里稳定性最好的——共鸣 1~2 的低门槛件铺场即法力，被清一次阈值不跳水太多，终章齐鸣自带清场、衍生物铺场自带续航；艾莉丝的征募 4 让浓度几乎翻倍。单卡质量平庸拖了上限，但对任何颜色都有「铺不满也能拖」的退路。

### 后三

9. **蓝**：有冻结、有反击、有抽爆，**但没有赢比赛的手段**。大生物只有 4/3/5、直伤为零、清场是回手不解场；纯被动套牌在「20 血倒计时」规则下等于把节奏全部让出，对红几乎auto-lose。引擎再华丽也救不了没有终点。
10. **紫**：理论上限（D12+奇点 9 点、终焉清场）是全环境最高的，但 0.5 级方差（骰运+混沌）+ 最差的常规过牌 + T1~T4 零场面，三个短板叠加导致「应然」和「实然」差距过大。上下限差距太大的套牌在单轮构筑赛里不可托付。
11. **青**：引擎（回响/连击/涡流/流转抽牌）是全游戏设计最精巧的，但 6 费法力上限 + 最大生物 5/4/7 + 唯一直伤是「每切潮 1 点」——**能打不能赢**。潮汐还是双方共享相位，对手退潮时深海重压 4 点可能帮对面解自己的衍生物。排名垫底不是引擎差，是终点缺失最严重。

（中间五位的简评：绿是教科书式加速中速但拍一被抢血；粉的骑升上限真实存在但被 0.5 成功率与限打 2 张双重封顶；金最独特但行动值链一断就崩、且没有特殊胜利兜底；黑引擎自洽但终结太依赖魂铸素材浓度；白曲线顺滑但抽牌太慢、无穿防、无直伤。）
