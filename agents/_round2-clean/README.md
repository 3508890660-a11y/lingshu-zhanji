## 一、为什么要重跑

上一轮的任务说明要求子代理读 `README.md` 第 4/5 节与卡表原文。而这两份材料里都藏着平衡结论：

| 位置 | 泄漏内容 |
|---|---|
| `README.md` §9 / §10 | 11 色循环赛胜率（青 69%、银 96%、极差 43）、紫 23%→41% 等 |
| `README.md` §5.6.1 | 39 条 bug 清单里夹着逐色胜率 |
| 卡表原文开头 | 「平衡基准 M23 口径 · 11 色落在 47~57」 |
| 卡表正文 `>` 注记 | 「对红胜率 5%→25%」「紫 11%→44%」「行动值 1→24%／3→83%」等 |
| 卡表 §七 | 「与 M23 平衡参数的对应」整节 |

结果就是 **11/12 个模型自选青、1 个选银**——那不是"自行挑选颜色"，是照着答案抄。

本轮把信息源换成封闭资料包 `agents/brief/`，四个文件之外的一切材料都列为未授权（含 README 全文、卡表原文、`js/engine/rules.js`、`js/ai/*`、`tools/*.mjs` 源码、赛果、上一轮产物、其他 subagent 产物），并在任务说明里禁止搜索全仓库、禁止联网、禁止询问主代理选色。

## 二、资料包怎么来的

`tools/make-clean-brief.mjs` 从卡表原文按固定区间抽取，生成 `agents/brief/02_卡表.md`：

## 五、两轮对照能看出什么

| | 上一轮（读得到平衡数据） | 本轮（封闭资料） |
|---|---|---|
| 颜色分布 | 11 青 / 1 银 | 红 6 / 绿 3 / 银 2 / 白 1 |
| 冠军 | KIMI 2.8preview · 青 · 潮汐涌动 84.09% | hy4 · 红 · 赤刃三段抢血 76.14% |
| 冠亚差 | 17.61pp | 5.69pp |

- **上一轮的"11 个选青"确由平衡数据驱动**：把资料换成纯卡面后，青直接归零。
- **模型自选与引擎实测强度不是一回事**：纯净资料下最常被选中且夺冠的是红（卡面直白：低费冲锋 + 直伤），而规则书平衡实测里强度居首的色没有任何模型选；绿色的地标 ramp 在 6 份红色快攻面前垫底。这是"卡面直观可读性"与"引擎结算强度"的偏差，不是平衡结论。
- **同色内差异仍巨大**：6 份红从 76.14% 到 39.77%，说明 `build` 的曲线与 `choose` 的动作优先级比选色更决定胜负。

> 以上对比只写在交付文档里，**不进资料包**；子代理全程看不到。
