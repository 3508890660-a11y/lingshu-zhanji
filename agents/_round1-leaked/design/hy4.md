# 一、颜色与卡组构想

选**青**，因为它是这套「连打换资源、铺场换身材」打法唯一在引擎层被完整激励的颜色：法力每回合增长（`min(回合+1, 6)`，灵体温蒂妮被动再 +1）、回合开始抽 2、**回合末按本回合打出数 `⌊plays/2⌋` 额外抽**（流转）。也就是说「一回合打得越多 → 下回合手越多 → 又能打更多」，是一个正反馈的自循环；而别的颜色要么消耗后不返牌（白/黑/绿/橙），要么把费用做成门槛不消耗（红/蓝/银/粉），都没有这种「用出牌数直接换牌」的杠杆。青的回合末抽牌奖励，是「潮涌连打」这个名字的来历。

配套的另一条是**涡流**：LQ01-140 的 ATK 随本回合出牌数增长（引擎按 `涡流X` 在 `unitAtk` 里结算，且本版对涡流关键词做了双计），一回合连打 3 张以上，它就从 3/2/4 变成 9 攻级别的打手。低费牌铺得越密，它越大——正好和「多打」同向。

三张撑起胜利方式的关键卡（数值均取引擎实装口径）：

- **LQ01-138 连击共鸣**：法术，`法力1`，抽 2。1 费换 2 张牌，净赚 1 张手牌且计入「流转」出牌数，是整个连打循环的润滑件；没有它，回合开始 2 张 + 温蒂妮 1 张撑不起一回合 4~6 张的出牌量。
- **LQ01-140 涡流长老**：单位，`法力4`，`3/2/4`，关键词 `涡流3`。本回合每出 1 张卡 +1 ATK（引擎双计，随 plays 最高约 +6），在铺场回合可达 9 攻；把「多打」直接兑换成场面压力，是这套的主题打手。
- **LQ01-136 月潮终曲·海灵圣母**：单位，`法力6`，`5/4/7`，战吼「你的单位 +1/+1」。低费小单位铺满后一次性全体放大，把一地 1/1、2/2 变成能破关的收束技，也是全牌唯一 5~6 费卡位。
- 辅助件：**LQ01-131 深海重压**（法术 `法力3`，对 1 个单位造成 3 点伤害，唯一点杀，处理对手大威胁/守卫）、**LQ01-133 潮卫·堤灵**（单位 `法力3`，`2/2/4` 守卫，稳场面护脸）。

# 二、核心思路

定位：**低费铺场的中速节奏（tempo / go-wide）**，不是纯快攻、也不是控制。

资源怎么滚起来：法力前期 2→3→4→5→6（温蒂妮被动让实际可用值再多 1），逐回合变宽；青回合开始抽 2、温蒂妮启动免费抽 1、`连击共鸣` 1 费抽 2，共同保证每回合起手 5~7 张；`choose` 优先把可负担的牌尽量打出去，触发回合末流转 `⌊plays/2⌋` 再补 1~3 张，形成「打得多→抽得多→下回合还能打得多」的循环。法力是**消耗型**（打出即扣），所以决策上把高费/高价值牌趁法力足先打，避免末尾只剩费用没有便宜牌可喂。

胜利方式：前 1~2 回合铺 1~2 费单位（回合 1 因召唤失调不能攻，属正常蓄势），第 2~3 回合起旧单位逐回合打脸压血，同时继续铺场；`涡流长老` 在连打回合膨胀、`月潮终曲` 在第 5~6 回合给全场 +1/+1，凑出一波高冲击的集体攻击把对手 20 张生命卡打空。不靠单卡偷跑，靠「场面宽度 × 每回合攻击次数」。

# 四、动作优先级

`choose` 只排序、只从引擎枚举的合法 `moves` 里返回一个对象引用；优先级自上而下：

1. **斩杀**：若所有可打脸攻击的 IMP 之和 ≥ 对手生命，直接连续取打脸攻击结束本局，不再把动作浪费在出牌上（单发斩杀在攻击估值里额外 +1000）。
2. **早期灵体启动**：温蒂妮启动是免费抽 1（`timing: early`），先开再出牌，等于本回合多一张可打；`used` 复位后每回合各开一次。
3. **出牌**：`plays < 12` 时取估值最高的一张。估值 = 基础分 + 高费优先（趁法力足先打大牌）+ 单位身材/关键词（`涡流`/`冲锋`/`守卫` 加权）+ 效果分（抽牌权重最高，其次点杀/AOE/群体 buff）；需指定目标的卡按目标质量择优（点杀优先能打死的高威胁，buff 优先给最高攻友军）。**每回合 12 张上限**是防「抽牌→连打→再抽」把单回合拖成长局的保险丝。
4. **后期灵体（rally 类）**：若灵体是「本回合群体 +IMP」型（`timing: late`），出完牌、进攻前再开，让增益吃到本次攻击（青的温蒂妮是 early，此步不触发，保留作通用兜底）。
5. **攻击**：只要有合法攻击就取估值最高者；打脸基础分最高（持续压血、推动收敛），单位互击按「能打死 / 会不会战死」给分，亏本交换排最后但**仍会出手**——始终保持进攻压力，避免双方对峙拖成长局；攻击会标记单位 `attacked`，循环必然收敛。
6. **升灵**：主动放弃。理由见第五节。
7. **购买**（仅金色方有，青不触发）、**pass**：其余情况安全收尾；未知 `moves` 类型一律不主动取，兜底回 `pass`。

`block()` 不实现，走引擎 `defaultBlock`：它持有 `g.pending`（攻击方/IMP/攻击者）的完整信息，比脚本只能看到的 `view` 更适合判断「能换就换、会被打死才挡」。全函数用 `try/catch` 包住，任何异常回落到 `moves` 末位的 `pass`，不向引擎抛错。

# 五、特殊机制适配

- **法力 / 流转（核心）**：法力是消耗型、随回合成长到 6（温蒂妮被动再 +1）；回合末 `⌊plays/2⌋` 额外抽。估值里「高费优先 + 抽牌高权重 + 出牌上限 12」就是围绕这两条写的：先把大牌打出去，再用低费牌把 plays 抬起来吃流转。青回合开始抽 2、蓝的「手牌无上限」与弃至 7 都不适用于青。
- **潮汐相位**：青每打出一张青色卡切一次涨/退；`127`/`136` 的 `潮汐` 关键词在涨潮时 +1 ATK（`unitAtk` 实装）。脚本不强行控相位（收益小、且切换由引擎自动做），只把它当免费身材加成接受。
- **涡流 / 回响**：`140` 的 `涡流3` 随 plays 增攻，是「多打」的核心兑换；`137` 的 `回响` 在引擎里只重结算非单位卡效果，对单位无额外收益，按普通 2/1/2 使用，不为它牺牲节奏。
- **灵体生命 / 生命卡**：胜负按生命卡组剩余张数（初始 20）；受伤逐张翻入损伤区并触发特效（青的 SM01 有抽 1 / 产法力 / 回 1 等）。脚本不主动自伤（那是黑/红的身份），只靠打脸压对手生命卡；青色生命卡特效是挨打时的「回响」，属被动收益。
- **外枢 / 升灵**：青有 3 张外枢（275/276/277），但升灵要**献祭己方场上单位**凑 SR 合计；本套靠「宽场」赢，献祭会把铺开的场面拆成一张大怪，反而损失每回合的攻击次数与流转基数。故 `choose` 明确不取 `ascend`，把它们当可选额外卡组搁置——不取不影响回合推进。
- **门槛色 / 地标 / 锻造区 / 市场 / 骰池**：均与青无关。青是消耗型资源（非门槛，无每回合出牌上限），故不套用蓝 2 / 银 3 / 粉 2 的闸门逻辑；地标不产青的法力（法力按回合算），锻造区（橙）、市场/购买（金）、骰池（紫）都不进入青的卡组与决策。灰色 `通用N` 虽允许混入，但会与青卡抢同一份法力、又不带潮汐/流转/涡流协同，故整副保持纯青。

# 六、取舍与已知弱点

**取舍**：为吃满「流转 + 涡流」的连打收益，把曲线压得很低（1–2 费 15 张、5–6 费仅 3 张），代价是后期单卡质量薄、几乎全靠 136 一张终结件撑上限；同时放弃升灵带来的高身材外枢，换取场面宽度与攻击次数。不混灰是为了让每一张牌都能吃到青的相位/流转/涡流协同，宁可少几张「补缝」件。

**已知弱点**：
- **怕清场 / AOE**：宽场小单位最怕白 `圣光震荡`、青 `风暴脉冲`、橙 `淬河` 一类群体伤害；一发 AOE 会让 1/1、2/2 全灭，铺场基数与涡流涨幅一起归零，节奏断档。带 131 点杀与 133 守卫只能缓解，不能根治。
- **怕大守卫 / 高耐久墙**：对手站住 2/2/6 一类守卫时，face 攻击被引擎强制改打守卫，小单位换不动，「一直进攻但仍打不到脸」会拖长对局。靠 140 膨胀与 136 的 5/4/7 + 全体 buff 破关，但成型在第 5~6 回合，前期被压住就难翻身。
- **怕快攻抢血**：回合 1 单位不能攻（召唤失调），前两回合几乎没有 face 伤害；红/银这类一回合就能铺开冲锋的快攻，可能在 136 上手前把 20 张生命卡打掉一大截。
- **长局保险**：第 20 轮起双方每回合各受 2 点灼烧，任何对局都会在有限步内结束；脚本始终进攻、出牌设上限 12，避免出现「双方都不出手」的僵局。

即便如此仍这样选：在引擎当前口径下，「出牌数 → 抽牌 / 涡流身材」是唯一被规则直接奖励的连打杠杆，青的低费宽场能把这条杠杆吃到最大；对上偏慢的控制/中速对手，稳定的铺场与每回合压血比赌单卡上限更可靠。
