# 赤焰速攻 · 设计说明（mimov26pro）

> 主色：**红**｜策略名：**赤焰速攻**｜执行模型：mimo-v2.6-pro
> 依据：`agents/color-reviews/mimov26pro.md`（十一色构筑潜力评价）＋ `agents/brief/01~03`（规则／卡表／接口的引擎实装口径）

## 一、颜色与卡组构想

**选色：红，直接取我自己评价排第 1 的颜色。** 评价《十一色构筑潜力评价》的「我的排序」表把红色排在构筑潜力第 1 名，核心理由原话是：

> 「快攻节奏稳定，激情门槛不消耗，手牌弃光机制明确可控，T1-T5 施压窗口清晰」

「前三理由」第 1 条又补了一次：

> 「激情门槛不消耗 = 打牌不扣资源，手牌弃光再补机制明确（激情越高补牌越少），T1-T5 就能打出 4-6 点直伤，快攻节奏最稳定。」

这两条正好就是构筑的两条骨架：**门槛不消耗 → 每回合可倾泻手牌**；**弃光重抽曲线 → 只有 T1-T5 的窗口期**。评价里红色的结构性弱点（「无升灵，缺后期大终端，打不死就输」「手牌管理极端」）不是劝退项，而是把这套牌钉死为**纯快攻**的约束条件——既然 T5 起手牌归 0，就不做任何后期计划，全部资源换成窗口期内的输出。

**但卡位不能照抄评价的「必带」表。** 评价是按卡面文本做的（那是「规则意图」），而 01 明文规定「两者冲突时以本文件为准」。按引擎实装口径逐条核对后修正了三处关键认知：

1. **直击灵体按 IMP 结算，不是 ATK**（01 §5「目标＝灵体：IMP 直击」）。于是「脸伤」要按 IMP 估值：暴走狂犬 1/**3**/2 一回合直击 3 点，是全池最强脸伤件；赤刃幼虎／熔岩裂爪只有 IMP1，从评价的必带表里出局。
2. **灵体狂战士·拉格纳（LQ01-221）被动给全体单位「冲锋」**。所有单位进场即打即攻，「战意永燃」的全体冲锋与光环重复，直接弃用；卡面的「怒火」「过载」等追加效果在引擎里没有对应实现，烽燧传令官的「免费打出」未实装（引擎里是 1/1/2 白板），也出局。
3. **红色回合末是「弃光再重抽 (10−激情)÷2」**：T1→4 张、T2→3、T3→2、T4→1、T5 起 0 张。没打出去的牌一律蒸发，所以打法必须是**每回合把手牌打空**，而不是留牌运营。

卡组构想一句话：**在 5 回合弃光窗口里，用全体冲锋的单位 + 点杀清障 + 直伤，把对手 20 点生命打穿。**

## 二、核心思路

**伤害构成（按引擎口径）**
- 单位脸伤 = 该单位的 IMP：暴走狂犬 3、烬原猛虎／战鼓蛮兵 2、怒火新兵／掷火散兵／血斧掷颅手 1；
- 进场直伤：掷火散兵、血斧掷颅手战吼各烧 1；
- 法术直伤：焚天血咒 4 点走脸；
- 团队泵：灵体启动「全体 IMP+1」＋ 战鼓蛮兵战吼「全体 IMP+1」，人越多越疼；
- 合计：一副 30 张里 21 个冲锋打手 + 6 张点杀 + 3 张直伤，期望 T4-T6 打穿 20 点。

**输出路径：清障 → 铺场 → 泵 → 走脸。**
对手挡脸的手段有两层，必须分开拆：
- **守护X**（白的奥蕾莉亚给全体守护1）会**自动拦截**直击：拦截条件是「打不死它，或它快死了」。对策是用 ATK≥3 的单位（血斧掷颅手／烬原猛虎／战鼓蛮兵）打穿 2 血守护单位（`max(0,3−1)=2 ≥ hp` 不触发拦截），或者用焚心咒／烈阳断刃把守护单位点掉。
- **挡板**（对手 block 窗口）按引擎内置的 defaultBlock 打分：只在「挡不死我方攻击者 / 能杀攻击者 / 自己快死了」时才挡。**我方 ATK ≥ 对方 HP 且对方 ATK < 我方 HP 时，挡板会送死，它就一定不挡 → 脸伤必通**。脚本把这条件写成「连通判定」，直击斩杀（+100 分）只在真正连通时生效。

**资源纪律**：激情是门槛、不消耗，打出不扣点数；唯一的代价是回合末弃光。因此**不保留、不囤积**，能打就打——哪怕点杀砸在一个杀不掉的大单位上，也比弃掉强。

## 四、动作优先级

`choose(view, moves)` 每次只挑一个动作，按下面五级瀑布；任何一级命中就返回：

1. **直伤斩杀**：手里的焚天血咒 ≥ 对手生命 → 直接打，当场结束。
2. **点杀**：焚心咒（4 点）／烈阳断刃（3 点）挑目标。评分 = 能杀 +20 ／威胁（ATK+IMP）／守卫·守护 +8 ／尚未行动（会来挡脸）+3。能杀优先；杀不掉也打最贵目标（反正回合末要弃）。
3. **倾泻手牌**（红色纪律）：
   a. 先下无目标的单位与直伤（费用升序）；
   b. 燃焰卫士选**当前 ATK 最高**的己方单位给永久 +1/0；
   c. **战鼓蛮兵最后下**——它的战吼泵只作用于当前场面，最后下才能让全队吃满 IMP+1。
4. **灵体启动**（全体 IMP+1）：牌全部打空后再开——启动要扣 1 点激情门槛，先开会把 4 费牌闸死。条件：场上有未攻击单位。
5. **攻击**：对每个攻击动作算「折算价值」取最大者，正收益才出手：
   - 直击：先判守护拦截（会被拦就按交换估值，不硬送）；再判挡板——若对手会挡，按「与最坏挡板的交换」估值；真正连通时 = IMP，且 IMP ≥ 对手生命时 +100（斩杀最优先）；
   - 打单位：标准交换估值（杀且活 3+威胁／杀而死 0.5+0.3×威胁／白蹭 0.2／送死 −2）。
   全部非正收益或无可动单位 → `pass`。

`block(view, bmoves)`（接口不暴露攻击者身份，只做两种有把握的阻挡）：
- **绝对优势阻挡者**（ATK ≥ 对面全体 HP 且对面全体 ATK < 自己 HP）→ 白赚一挡；
- **危险血线**（我方生命 ≤ max(4, 对面最高 IMP)）→ 用 ATK+IMP 最小、耐久优先的单位垫刀保命；
- 其余一律不挡——红色是竞速方，单位即输出。

`respond(view, ctx, moves)` 只在**攻击响应窗口**出手：烈阳断刃 3 点把攻击者点死（伤害不落）。出手条件：能杀（HP≤3）且威胁足（脸伤 IMP≥2 / 单位战 ATK≥2，或我方生命危险）。ctx 不暴露攻击者 uid，用「卡名+ATK+IMP+HP」在 view.opp.board 里**唯一匹配**才动手，认不出就放过，绝不乱打。出牌/回合结束窗口一律 pass（瞬间牌留到自己回合当普通点杀用——手牌反正过不了回合末）。

## 五、特殊机制适配

| 机制（01 口径） | 本卡组的适配 |
|---|---|
| 脸伤＝IMP、单位战＝ATK | 选卡按 IMP 估脸伤、按 ATK 估交换：暴走狂犬（IMP3）核心，赤刃幼虎/熔岩裂爪（IMP1）出局 |
| 灵体拉格纳全体冲锋光环 | 全员即打即攻；「战意永燃」与光环重复弃用；无召唤失调顾虑，T1 即可打脸 |
| 弃光重抽 (10−激情)÷2（4/3/2/1/0） | 每回合倾泻打法；不留牌、不做后期；T5 前必须分出胜负 |
| 激情门槛不消耗＋无出牌上限 | 一回合把手牌全打光；泵（战鼓蛮兵）压轴下 |
| 灵体启动扣 1 点激情 | 先出牌、后开泵、再攻击，4 费牌不受挤占 |
| 战吼泵只作用当前场面 | 战鼓蛮兵在单位全部进场后最后一个下 |
| 守护X 自动拦截直击 | ATK≥3 打穿 2 血守护单位；或点杀守护单位再走脸 |
| 守卫强制攻击目标 | 优先点杀守卫（+8 分），拆掉后才恢复直击通道 |
| 挡板窗口（defaultBlock 打分制） | 连通判定＝「ATK≥对方 HP 且对方 ATK<自己 HP」；连通才计全额脸伤 |
| 瞬间/响应链（规则 3.6） | 带 3 烈阳断刃：主阶段当点杀，对手攻击窗口当「先手去除」点死攻击者 |
| 重构（牌库空洗回、激情减半） | 30 张只见到约 13 张，窗口期不会打空牌库，重构惩罚天然规避 |
| 残响回收（LQ01-288）自回收 | 引擎先推弃牌区、recover 又弹回自己，是无限空转陷阱 → 脚本永不打这张（兜底补位也排除） |

## 六、取舍与已知弱点

**取舍（评价必带表 → 引擎实装口径的修正）**
- **弃：烽燧传令官**（免费打出未实装，引擎里是 1/1/2 白板）、**战意永燃**（全体冲锋与光环重复，减伤未实装）、**余烬掌控**（无过载触发，只剩一次性抽 1）、**血红爆发／怒火重燃**（6/3 费一次性 IMP 泵，不如战鼓蛮兵留场）、**熔火爆破**（随机 2 目标，不稳）、**赤刃幼虎／熔岩裂爪**（IMP1 脸伤太低）。
- **不混灰色泛用**：借律（全队永久 +1/0）与遣返（弹回/消衍生物）单看可用，但要挤掉红色打手，损失的是窗口期内的输出一致性；残响回收则是自回收陷阱，明确排除。纯红 10 名目 ×3 的密度是「5 回合打穿 20 血」的最低配置。
- **燃焰卫士保 3 张**：2 费 2/2/2＋永久 +1/0，虽有「场上先有单位」的下场顺序依赖，但脚本的出牌瀑布天然先下无目标件，buff 顺带喂给 ATK 最高者，实测无卡手。

**已知弱点**
1. **T5 起手牌归 0**：弃光重抽 (10−激情)÷2 ＝ 0，之后只能靠场上残余单位。打不死就输——这是红色的结构性代价，用曲线（1/2 费 15 张）把窗口期输出压到最满来对冲。
2. **怕守护+守卫叠厚**（白·奥蕾莉亚开局全员守护1＋衍生物）：低 ATK 单位（暴走狂犬）会被守护单位免费吃掉，必须靠点杀开路，点杀断档就拖进长盘。
3. **斩杀会被守护拦截**：对手生命 ≤ 我方 IMP 时守护单位会自杀式拦截，最后一步经常要先点掉守护再走脸，多耗一张牌。
4. **暴走狂犬怕高攻挡板**：它脸伤 3 但 ATK 只有 1，遇到任何 2 血以上挡板都换不动，只能等清障后收割。
5. **无后期、无回复、无升灵**：评价的红色弱点原样保留；拖过 T7 基本判负。
6. **重构把激情减半**：极端长盘若被迫重构，门槛腰斩后连 4 费牌都闸死（窗口期不会触发，长盘才可能）。
7. **响应匹配有理论误差**：ctx 不给攻击者 uid，靠「卡名+身材」唯一匹配，对手双胞胎身材同名牌时会放弃响应（宁可不打，不乱打）。
