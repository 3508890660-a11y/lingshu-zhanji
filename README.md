# 灵枢战纪

一个自研集换式卡牌游戏（TCG）的规则引擎、观战台与 AI 实验台。

11 色、5 种飞升仪式、30 张卡组、20 张生命卡。仓库里是一个可运行的无头引擎、一个本地观战台，以及 12 个真实模型在三种提示策略下的构筑实验（每轮 300 局，共 900 局）。

## 快速开始

```bash
node server.mjs
# 浏览器打开 http://127.0.0.1:5173/
```

无第三方依赖，Node 18+。

跑一局自检：

```bash
node tools/agent-selftest.mjs agents/agent-hy4.js 绿 20
```

跑一轮瑞士轮（12 个脚本，5 轮 BO10）：

```bash
node tools/agents-swiss.mjs --rounds 5 --bo 10 --out agents/results
```

## 12 模型实验

三轮，同一赛制（5 轮瑞士 + BO10，每轮 300 局），每轮只改变一个变量：

| 轮次 | 变量 | 结果 |
|---|---|---|
| 一 | 统一提示词，自行选色 | 绿 7 人、橙 2、红 1、黑 1、蓝 1；冠军是唯一的红（86%） |
| 二 | 只告知「你自己的上一轮胜率」 | 5 升 3 降：能修执行 bug 的涨（+21、+14），方向误判的崩（−36） |
| 三 | 先评 11 色，再由新 subagent 依自评选色 | 绿降到 5、红升到 4，红系占前二（86%、80%） |

三轮的均值都是 50%（零和），标准差 16.27 / 17.40 / 16.68——**选色分布变了，牌桌的整体强度没变**。真正的收益是让被埋没的颜色被看见：统一轮只有 1 人选红，评色轮 4 人选红。

完整过程与判据见 `agents/实验时间线.md`、`agents/评色与选色.md`。
